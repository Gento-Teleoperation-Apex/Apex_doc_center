# Apex Teleop 使用说明

Apex Teleop 是 KernelMind Apex 产品线的上位机控制软件，用于连接机器人控制器、管理遥操模块、切换控制模式、查看相机画面，以及录制、回放和排查运行日志。

## 版本适用范围

| 产品 | 使用界面 | 说明 |
|---|---|---|
| Marvin Pro（当前天准版本） | [当前版界面](/software/apex-teleop/pro-current) | 本文档以 Apex Teleop `1.0.7.6o` 对应界面为例 |
| Marvin Pro（历史 Orin 版本） | [经典版界面](/software/apex-teleop/classic) | 面向已出货历史设备 |
| Skye / Luna | [经典版界面](/software/apex-teleop/classic) | 继续使用经典界面和 Pico 全身遥操套件 |

软件版本会持续更新，现场安装包应与控制器端 KernelMind Apex 软件保持配套。
