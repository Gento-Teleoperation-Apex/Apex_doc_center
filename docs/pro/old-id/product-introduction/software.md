# 软件

## KernelMind Apex

KernelMind Apex 是安装在 Orin 主控上的机器人遥操作软件系统，分为两个部分：

- **Orin 端**：`kernelmind-apex_<version>_arm64.deb`，提供 ROS 2 节点服务和运动控制逻辑
- **头显端**：`KernalMind_Apex_meta_<version>.apk`，运行在 Meta Quest VR 头显，提供沉浸式操作界面

### 系统要求

| 项目 | 要求 |
|---|---|
| 操作系统（Orin） | Ubuntu 22.04 ARM64 |
| 机器人框架 | ROS 2 Humble |
| 头显 | Meta Quest（通过 ADB 安装 APK） |

## 控制模式

机器人启动后可切换三种控制模式：

| 模式 | 用途 |
|---|---|
| 待机模式 | 初始化、错误恢复，不遥操时建议切换到该模式 |
| 位置模式 | 精确位置控制 |
| 阻抗模式 | 力控交互、拖动示教、遥操控制（遥操时使用） |

![遥操软件控制模式](/img/pro_p28.png)

## 速度调节

- `Slow`：较慢移动速度
- `Fast`：较快移动速度

速度只允许在**待机模式**下切换。

![速度调节](/img/pro_p29.png)

## 数据录制

1. 点击主面板「数据录制」。
2. 点击「开始录制」。
3. 再次点击变为红色的「停止录制」按钮停止。
4. 数据保存到名为 `BAG_STORAGE` 的 U 盘，目录格式：`my_bag-年-月-日-时-分-秒`。
   - `data/`：ROS bag 数据
   - `video/`：MP4 视频

> U 盘插入后才有录制功能。

![数据录制功能](/img/pro_p30.png)

## 复位与实机回放

**复位**：遥操或实机回放后点击「复位」，机械臂回到默认初始 Home 点位置。

![复位功能](/img/pro_p31.png)

**实机回放**：选择已录制 bag 文件并点击播放。

> 注意：遥操时不能回放，回放时不能遥操。

![实机回放功能](/img/pro_p32.png)

## 夹爪重启

夹爪断连或热插拔后，点击「夹爪重启」恢复夹爪状态。

![夹爪重启功能](/img/pro_p33.png)
