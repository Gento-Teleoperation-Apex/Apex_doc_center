# 产品概述

## 产品定位

KernelMind Apex 是一套面向机器人遥操作场景的即装即用套件，通过 VR 头显为操作员提供第一视角沉浸式视角，并将操作员动作实时映射到机器人端执行。

Marvin Pro 旧ID 版本支持双臂机器人遥操，搭配 Meta Quest VR 头显与 NVIDIA Jetson Orin 主控。

可选配件：Manus 数据手套 + Wuji Hand，用于手部动作捕获与精细操控。

## 系统组成

Marvin Pro 遥操系统主要包括以下设备：

- 双臂机器人本体
- 机器人控制器
- 48V 主电源（220V-48V 开关电源）
- 12V 控制器电源
- 急停按钮盒
- NVIDIA Jetson Orin 主控
- 相机解串板（支持 4 路 GMSL 相机）
- VR 头显（Meta Quest）与手柄
- 路由器与网线
- U 盘（用于数据录制，标签需为 `BAG_STORAGE`）

![Orin 与 VR 套装设备清单](/img/pro_p10.png)

网络连接建议：机器人控制器、Orin、VR 头显适配器通过网线接入同一台路由器。

![网络连接清单](/img/pro_p11.png)

## 核心能力

- 低延迟 VR 视频回传，支持 GMSL 多路相机（左目、右目、左腕、右腕）
- 毫米级空间追踪，实时动作映射至机械臂
- 支持阻抗模式、位置模式、待机模式等多种控制模式
- 内置 ROS bag 数据录制与实机回放功能
- 支持脚踏板扩展及增量遥操模式（出厂默认）

## 典型应用场景

- 双臂机器人远程遥控操作
- 危险环境下的机器人代人作业
- 机器人示教数据采集
- 工厂智能化生产辅助
