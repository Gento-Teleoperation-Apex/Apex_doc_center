# 产品组成

## 主控与电源

| 组件 | 说明 |
|---|---|
| NVIDIA Jetson Orin | 主控计算单元，运行 KernelMind Apex 系统 |
| 220V-48V 开关电源 | 双臂机器人主动力电源 |
| 12V 控制器电源 | 机器人控制器供电 |
| 急停按钮盒 | 串入机器人急停控制回路，紧急停机用 |
| 泄放模块 | 并接到 48V 电源正负极，保护电路 |

## 相机解串板

相机解串板安装在 Orin 底部，通过 GMSL 接口接入最多 4 路相机。接口编号与相机对应关系：

| 解串板接口编号 | 对应相机 |
|---|---|
| 8 | 左目相机 |
| 6 | 左腕相机 |
| 7 | 右腕相机 |
| 0 | 右目相机 |

### 接线清单

相机与外设接线时，先按接口编号插入对应相机线，再连接数据录制 U 盘、通信网线、解串板电源和 Orin 电源。

| 接线项目 | 连接说明 |
| --- | --- |
| 相机线 | 插入解串板对应接口，确认接口编号与相机位置一致 |
| U 盘 | 接入 Orin，用于数据录制，标签需为 `BAG_STORAGE` |
| 网线 2 | 接入 Orin，与机器人控制器和 VR 头显适配器保持同一路由器网络 |
| 解串板电源 | 接入解串板供电接口 |
| Orin 电源 | 接入 Orin 主控供电接口 |

### 上电检查

| 步骤 | 操作 | 检查点 |
| --- | --- | --- |
| 1 | 先给解串板供电 | 等待约 10 秒，确认解串板进入稳定供电状态 |
| 2 | 再给 Orin 上电 | 等待约 1 分钟，确认 Orin 启动完成 |
| 3 | 检查指示灯 | 确认四个相机接口指示灯常亮 |

## 通信网络

建议通过有线网络将以下设备接入同一路由器：

| 设备 | 默认 IP |
|---|---|
| 机器人控制器 | `192.168.10.190` |
| Orin 主控 | `192.168.10.123` |
| VR 头显适配器 | 路由器自动分配 |
