# 硬件接线

本节介绍 Marvin Pro 双臂机器人系统的供电接线、通信网络连接、初始姿态设置，以及 Orin 与相机解串板的安装步骤。

> 接线前务必断开总电源。

## 1. 双臂供电与通信接线

### 1.1 接线步骤

在断开总电源的情况下完成以下接线：

1. 将双臂机器人 `48V+` / `48V-` 接入 `220V-48V` 开关电源的直流输出正负极。
2. 将泄放模块 `48V+` / `48V-` 并接到同一 48V 电源正负极。
3. 将急停按钮盒串入机器人急停控制回路。
4. 左臂 / 右臂 `ethcart` 网口分别连接到机器人控制器对应网口。
5. 将 12V 电源连接机器人控制器，并将上行网线接入局域网路由器。

![双臂供电与通信接线说明](/img/pro_p05.png)

实物接口参考：

### 1.2 上电顺序

1. 先给 `220V-48V` 开关电源通电。
2. 再给机器人控制器通电。
3. 确认机器人控制器 IP 为 `192.168.10.190`。

![双臂上电与控制器 IP](/img/pro_p07.png)

## 2. 初始端平姿态

使用 `fxstation` 或 `MarvinPlatform` 软件，将双臂调整到初始端平姿态后再进行后续操作。

1. 切换到**位置模式**。
2. 进入**关节跟随模式**。
3. 写入以下点位：
   - 左臂：先 `[0, 0, 0, 0, 0, 0, 0]`，再 `[90, -90, -90, -90, 0, 0, 0]`
   - 右臂：先 `[0, 0, 0, 0, 0, 0, 0]`，再 `[-90, -90, 90, -90, 0, 0, 0]`
4. 点击加点并运行，默认速度 `20%`。

![初始端平姿态设置](/img/pro_p08.png)

## 3. Orin 与相机解串板安装

### 3.1 安装解串板

1. 拆下 Orin 底座，释放内部固定螺丝。
2. 安装解串板支撑柱。
3. 将解串板对齐支撑柱并锁紧。

相机接口对应关系：

| 解串板接口编号 | 对应相机 |
|---|---|
| 8 | 左目相机 |
| 6 | 左腕相机 |
| 7 | 右腕相机 |
| 0 | 右目相机 |

![解串板相机接口与上电说明](/img/pro_p16.png)

### 3.2 上电顺序

1. **先给解串板供电**，等待约 10 秒。
2. **再给 Orin 上电**，等待约 1 分钟。
3. 确认四个相机指示灯**常亮**。

> 如果指示灯未全亮，检查相机线束连接是否牢固。
