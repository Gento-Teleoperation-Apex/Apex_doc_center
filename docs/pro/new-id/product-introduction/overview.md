# Marvin Pro 天准版产品概述

## 产品定位

KernelMind Apex 是一套面向机器人遥操作场景的即装即用套件，通过 VR 头显为操作员提供第一视角沉浸式画面，并将操作员动作实时映射到机器人端执行。

PRO 新版正式名称为 Marvin Pro 天准版，支持双臂机器人遥操，搭配 Meta Quest VR 头显与天准核心控制器。新版使用天准控制器作为核心控制单元，解串板集成在机器人内部，森云相机为标配并通过手臂内部线束连接。

可选配件：Manus 数据手套 + Wuji Hand，用于手部动作捕获与精细操控。

## 系统组成

Marvin Pro 天准版遥操系统主要由机器人本体、机器人控制器、天准电箱、森云相机、VR 头显、上位机和数据录制介质组成。

| 类别 | 设备 | 说明 |
| --- | --- | --- |
| 机器人端 | 双臂机器人本体 | 执行遥操作动作 |
| 机器人端 | 机器人控制器 | 接收天准控制器与控制系统指令 |
| 电源与安全 | 48V 主电源 | 220V-48V 开关电源 |
| 电源与安全 | 12V 控制器电源 | 为控制器和相关外设供电 |
| 电源与安全 | 急停按钮盒 | 现场安全保护与紧急停止 |
| 主控 | 天准电箱 / 核心控制器 | 运行 KernelMind Apex 与 ROS 2 节点 |
| 感知 | 森云相机 | 标配相机，安装在机器人手臂末端，线束从手臂内部引出 |
| 操作端 | VR 头显（Meta Quest）与手柄 | 提供第一视角画面与操作输入 |
| 网络与数据 | 网线与 Type-C 网口转换器 | 连接电箱、上位机和 VR 头显 |
| 网络与数据 | U 盘 | 用于数据录制，标签需为 `BAG_STORAGE` |

## 可选配件

| 配件名称 | 说明 |
|---|---|
| Manus 数据手套 | 捕获手指精细动作，配合 Wuji Hand 使用 |
| Wuji Hand | 机器人灵巧手末端，接收手套动作指令 |
| 脚踏板（三键，非标配） | 将手柄使能映射到脚部，适用于动捕手套 / 灵巧手遥操场景 |

脚踏板三键功能：

| 按键 | 功能 |
|---|---|
| 按键 1（左键） | 左右手柄一起使能 |
| 按键 3（右键） | 两个手臂回到 Home 点 |

## 软件组成

| 软件模块 | 安装位置 | 说明 |
|---|---|---|
| KernelMind Apex 控制器端 | 天准电箱 / 核心控制器 | `kernelmind_apex_<version>_<arch>.deb`，提供 ROS 2 节点、运动控制、相机与录制服务 |
| KernelMind Apex 头显端 | Meta Quest | `KernelMind_Apex_meta_<version>.apk`，提供 VR 遥操作界面 |
| 上位机遥操软件 | PC | 用于连接天准控制器、启动机器人、切换模式、录制和回放数据 |

## 默认网络与运行环境

| 项目 | 默认值 / 说明 |
|---|---|
| 天准电箱 / 核心控制器 IP | `6.6.7.100` |
| 双臂控制板 IP | `6.6.7.190` |
| 上位机网卡 IP | `6.6.7.xxx`，例如 `6.6.7.165` |
| 头显 Apex 软件连接 IP | `6.6.7.100`，需与天准控制器 IP 一致 |
| SSH 登录天准控制器 | `ssh nvidia@6.6.7.100` |
| 天准控制器用户密码 | `nvidia` |

| 项目 | 规格 |
|---|---|
| 操作系统（天准控制器） | Ubuntu 22.04 |
| 操作系统（上位机开发） | Ubuntu 22.04 AMD64 |
| 机器人框架 | ROS 2 Humble |
| 主控硬件 | 天准核心控制器 |
| 头显 | Meta Quest（VR 端 APK） |
| 安装包格式 | `kernelmind_apex_<version>_<arch>.deb` |

## 核心能力

- 低延迟 VR 视频回传，支持森云相机与 GMSL 多路视频链路
- 毫米级空间追踪，实时动作映射至机械臂
- 支持阻抗模式、位置模式、待机模式等多种控制模式
- 内置 ROS bag 数据录制与实机回放功能
- 支持增量遥操模式；脚踏板为非标配扩展

## 典型应用场景

- 双臂机器人远程遥控操作
- 危险环境下的机器人代人作业
- 机器人示教数据采集
- 工厂智能化生产辅助
