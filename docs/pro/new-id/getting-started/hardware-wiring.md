# 硬件接线

本页用于 Marvin Pro 新版系统的现场接线检查，包含双臂供电、通信网络、初始姿态和天准核心控制器接线。

新版使用天准核心控制器作为主控，控制器自带相机接入能力。

> 接线前务必断开总电源。所有网线、电源线和相机线束确认插接牢固后，再进行上电检查。

## 1. 双臂供电与通信接线

在断开总电源的情况下完成以下接线：

1. 将双臂机器人 `48V+` / `48V-` 接入 `220V-48V` 开关电源的直流输出正负极。
2. 将泄放模块 `48V+` / `48V-` 并接至同一 48V 电源正负极。
3. 将急停按钮盒串联接入机器人急停控制回路。
4. 将左臂、右臂 `EthCart` 网口分别连接至机器人控制器对应网口。
5. 将 `12V` 电源连接至机器人控制器电源输入端。
6. 将上行网线（网线 1）连接至机器人控制器网络接口。

![机器人接线实物对照图](/img/pro/hardware_wiring_interfaces.png)

接线注意事项：

- `48V+` 与 `48V-` 极性必须对应正确，严禁反接。
- 急停按钮盒需处于释放状态后再启动系统。
- 首次使用或更换控制器后，确认机器人控制器 IP 为 `192.168.10.190`。
- 上电时先接通 `220V-48V` 开关电源，再接通机器人控制器 `12V` 电源。

## 2. 调整至初始端平姿态

使用 [`fxstation`](/files/FxStation.exe) 或 `MarvinPlatform` 软件，将双臂调整至初始端平姿态后，再进行后续遥操操作。下图以左臂为例，右臂步骤相同。

![初始端平姿态设置](/img/pro/hardware_initial_pose_ui.png)

操作步骤：

1. 输入机器人 IP 地址，默认 `192.168.10.190`，连接机器人。
2. 将机械臂切换至 **位置模式**。
3. 切换至 **关节跟随** 模式。
4. 在关节跟随模式下先回零位，再写入目标点位：
   - 左臂：`[0, 0, 0, 0, 0, 0, 0]` -> `[90, -90, -90, -90, 0, 0, 0]`
   - 右臂：`[0, 0, 0, 0, 0, 0, 0]` -> `[-90, -90, 90, -90, 0, 0, 0]`
5. 点击 **加点**，将当前点位加入轨迹列表。
6. 点击 **运行**，默认速度为 **20%**，使机械臂运动至目标姿态。
7. 运动完成后退出软件。

> 运行前请确认机械臂运动范围内无人员、设备或其他障碍物。

## 3. 天准核心控制器接线

天准核心控制器集成主控计算、网络、USB、供电、急停和相机接入能力。现场接线时按控制盒面板标识和线缆标签连接。

![天准核心控制器接口](/img/pro/new-id/tianzun-controller.jpg)

建议检查以下接口：

| 接口 / 模块 | 用途 |
|---|---|
| `ETHERNET1` / `ETHERNET2` | 接入机器人控制网络、路由器或上位机网络 |
| `USB1` / `USB2` | 接入 U 盘、调试设备或外设 |
| `HDMI` | 本地显示调试 |
| `ACIN` / `POWER` | 控制盒供电与电源开关 |
| `E-STOP` | 急停回路 |
| `DC48V` / `DC12V` 指示灯 | 检查 48V / 12V 供电状态 |

相机线束由天准控制器内置相机接入模块处理，现场按线缆标签确认连接即可。

## 4. 网络接线

机器人控制器、天准控制器和 VR 头显适配器需通过网线接入同一台路由器，保证三者处于同一局域网内。

| 网线 | 连接目标 |
|---|---|
| 网线 1 | 连接至机器人控制器 |
| 网线 2 | 连接至天准控制器 |
| 网线 3 | 连接至 VR 头显适配器 |

![PRO 网络连接示意图](/img/pro/pro_overview_network.png)

默认网络参数：

| 设备 | 默认 IP |
|---|---|
| 机器人控制器 | `192.168.10.190` |
| 天准核心控制器 | `192.168.10.123` |
| 路由器 | `192.168.10.1` |
| 头显 Apex 软件连接 IP | `192.168.10.123` |

## 5. 上电检查

| 步骤 | 操作 | 检查点 |
|---|---|---|
| 1 | 接通 48V 主电源 | 确认机器人端供电正常 |
| 2 | 接通控制器 12V 电源 | 确认机器人控制器正常启动 |
| 3 | 接通天准控制器电源 | 打开 `POWER`，等待系统启动 |
| 4 | 检查控制盒指示灯 | 确认 `DC48V` / `DC12V` 指示灯状态正常 |
| 5 | 检查相机画面 | 启动后确认头显或上位机能看到相机画面 |
| 6 | 检查网络 | 上位机、天准控制器、机器人控制器和头显处于同一网段 |

如果相机没有画面，优先检查相机线束、天准控制器相机接口、服务状态和网络信令地址。
