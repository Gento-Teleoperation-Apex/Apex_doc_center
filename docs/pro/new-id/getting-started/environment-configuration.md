# 环境配置

## 网络

| 设备 | 默认示例 | 要求 |
|---|---|---|
| 天准控制器 | `6.6.7.100` | 以现场交付地址为准 |
| 机器人双臂控制板 | `6.6.7.190` | 与控制器配置保持一致 |
| 上位机 | `6.6.7.xxx` | 与控制器同网段且地址不冲突 |
| Pico / Meta Quest | 同网段独立地址 | Apex 客户端连接目标填写天准控制器 IP |

```bash
ping 6.6.7.100
```

任何设备都不能使用重复 IP。修改现场网段前，应同步确认机器人控制板、天准控制器、上位机和头显配置。

## 软件配套

- 机器人控制端、Gento SDK、Teleop 遥操服务、Apex 前端和头显客户端应使用同一交付批次的配套版本。
- 当前 Pro 源码核对目标为 `gento-apex 1.1.7.1`，控制运行时使用 Gento SDK `4.7.1`；该目标在源码中仍标记为未正式发布，且不再以 MarvinSDK 作为控制运行时。客户现场版本以交付清单为准。
- 安装包名称随版本变化，以交付文件和发布说明为准。
- 末端执行器和 Camera 均按实际选配启用。

## 相机

前端固定显示四宫格。`camera_sources` 中未启用的位置会显示黑色，例如 `0, 1, none, none` 表示仅启用前两路，这属于正常配置。

相机编号、线束或标定参数需要调整时，请先备份配置并联系技术支持确认，不要在机器人运行时修改。

## 头显

Marvin Pro 支持 [Pico](/xr-teleop/pico) 和 [Meta Quest](/xr-teleop/meta)。头显必须与天准控制器处于同一局域网，头显客户端中的连接 IP 应填写天准控制器地址，而不是头显自身地址。
