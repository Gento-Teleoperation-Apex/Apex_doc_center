# Skye 产品概述

## 产品定位

Gento Skye 是一套可穿戴体感遥操系统，操作员穿戴 Skye 套件后，其肢体动作可实时映射到机器人端执行，无需手柄即可控制双臂机器人。

## 系统组成

| 组件 | 说明 |
|---|---|
| VR 眼镜 | 操作员佩戴，提供第一视角，默认 IP `6.6.7.100` |
| 操控手臂（左/右） | 穿戴在手臂上，捕获手臂运动 |
| 腰部传感器 | 佩戴在背部，捕获躯干姿态 |
| 脚环传感器 | 佩戴在脚踝前方，捕获步态信息 |

![Skye 产品组件实物](/img/skye/components.png)

## 穿戴说明

- **VR 眼镜**：长按 2 秒开机，长按 5 秒关机
- **腰部/脚环传感器**：长按 2 秒开机，长按 5 秒关机
- **腰部传感器**：佩戴在背后
- **脚环传感器**：佩戴在前方

## 网络配置

| 项目 | 默认值 |
|---|---|
| Skye VR 眼镜 IP | `6.6.7.100` |
| Orin DHCP 网段 | `6.6.7.x` |

VR 眼镜 IP 地址需修改为 `6.6.7.100`。

## 标准配件

| 配件名称 | 数量 | 说明 |
|---|---|---|
| VR 眼镜 | 1 | Skye 专用 VR 设备 |
| 操控手臂（左/右） | 各 1 | 穿戴式运动捕获手臂 |
| 腰部传感器 | 1 | 捕获躯干姿态 |
| 脚环传感器 | 1 | 佩戴于脚踝前方 |

## 配置文件清单

| 上传位置 | 文件 | 说明 |
|---|---|---|
| 天准端 | `kernelmind-apex_0.1.1g_arm64.deb` | 版本文件 |
| 天准端 | `dhcp_service.md` | DHCP 文件 |
| 天准端 | `install_van.sh` | install 文件 |
| VR 眼镜 | `0508ZJ_apex_MJPEG_wb(2).apk.1` | VR 端 APK |

更新版本时，先删除旧版本：

```bash
sudo apt remove kernelmind_apex
```

在下载的版本文件目录中打开终端，安装新版本：

```bash
sudo apt install ./<包名>
```
