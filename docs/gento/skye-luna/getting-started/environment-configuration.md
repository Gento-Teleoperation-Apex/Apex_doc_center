# 环境配置

## 网络

| 设备 | 说明 |
|---|---|
| 天准003控制单元 | 默认示例为 `6.6.7.100`，现场修改后以实际地址为准 |
| 上位机 | 与天准003处于同一网段，地址不得冲突 |
| Pico | 获取同网段独立地址；客户端连接目标填写天准003 IP |

```bash
ping 6.6.7.100
```

Pico 自身地址不能与天准003地址相同。调整现场网段时，应同时检查上位机、Pico 和网络服务配置。

## 穿戴与追踪

1. 区分左右操控手臂并固定可靠。
2. 腰部传感器佩戴在规定方向。
3. 腿部传感器按要求固定，避免松动和左右装反。
4. 检查所有组件电量、连接和追踪状态。
5. Home 后先进行小幅双臂测试；Skye 再检查躯干与升降映射，Luna 再检查躯干与腿部映射。

## 软件

Skye/Luna 当前正式文档基线为 `v1.1.7.1g`，使用 Gento SDK `4.7.1`。客户现场以交付清单中的控制端安装包为准；Teleop 遥操服务、Apex 前端和 Pico 客户端必须使用同一交付批次的配套版本，不应根据控制端包号推断各自版本。新版配套界面见 [Gento 当前版操作指南](/software/apex-teleop/gento-current)，历史界面见 [经典版 Apex Teleop](/software/apex-teleop/classic)。DAgger 功能另按交付清单和 [DAgger 使用手册](/vla/dagger) 核对，不由上述基线包号推断。
