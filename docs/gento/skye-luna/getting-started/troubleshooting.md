# 故障排查

| 现象 | 优先检查 |
|---|---|
| 无法连接天准003 | IP、上位机网段和网线 |
| Robot 启动失败 | 急停、机器人供电、Robot 日志 |
| 3D 姿态与实体不一致 | 机型配置、Robot 状态和关节反馈 |
| Pico 无法连接 | Pico 地址、连接目标、网络模块和网线适配器 |
| Skye 双臂可动但 BODY/LIFT 不跟随 | 机型配置、腰部/腿部传感器佩戴、电量和追踪状态 |
| Luna 双臂可动但躯干/腿部不跟随 | 机型配置、腰部/腿部传感器佩戴、电量和追踪状态 |
| Skye 前端未显示 VR Connected | Skye 当前版本不应只根据该状态判断；同时检查目标位姿和使能数据是否持续更新 |
| Luna 收到数据但无法遥操 | 头显到控制器的 TCP 会话、连接 IP、客户端版本及网络状态 |
| 动作方向错误 | 左右组件、传感器方向和 Home 初始姿态 |
| 相机无画面 | Camera 模块、四路相机连接和日志 |
| 遥操无动作 | Robot Ready、Impedance Mode、Home 和头显连接 |

发生异常运动、失衡趋势或机械干涉时立即按下急停。联系技术支持时提供机型、版本、故障时间、日志和传感器佩戴照片。
