# Skye/Luna 产品概述

## 产品定位

Skye 和 Luna 是支持全身遥操作的机器人型号，并不是遥操系统的名称。机器人出货时集成天准003控制单元、四路相机及遥操所需硬件。操作员佩戴 Pico 头显、手臂组件、腰部传感器和腿部传感器后，动作可实时映射到机器人的双臂、躯干和膝关节。

## 系统组成

| 组件 | 说明 |
|---|---|
| Skye 或 Luna 机器人 | 执行双臂及全身遥操作动作，包含膝关节 |
| 天准003控制单元 | 运行 KernelMind Apex 和 ROS 2 控制服务 |
| 四路相机 | 提供四宫格第一视角和环境画面 |
| Pico 头显 | 显示第一视角画面并提供头部追踪 |
| 操控手臂（左/右） | 捕获操作员双臂运动 |
| 腰部传感器 | 捕获躯干姿态 |
| 腿部传感器 | 捕获腿部和膝关节动作 |
| 上位机 | 运行经典版 Apex Teleop |

## 穿戴说明

- **Pico 头显**：佩戴后确认视野清晰，头带固定可靠。
- **操控手臂**：区分左右，固定后不得影响肘关节活动。
- **腰部传感器**：佩戴在背部并保持方向正确。
- **腿部传感器**：固定在规定位置，用于腿部和膝关节动作映射。
- 各追踪组件使用前应确认电量、连接和追踪状态。

## 标准配件

| 配件名称 | 数量 | 说明 |
|---|---:|---|
| Pico 头显 | 1 | Skye/Luna 全身遥操使用的头显 |
| 操控手臂（左/右） | 各 1 | 捕获双臂动作 |
| 腰部传感器 | 1 | 捕获躯干姿态 |
| 腿部传感器 | 按交付配置 | 捕获腿部和膝关节动作 |
| 网线 | 若干 | 连接机器人、上位机、交换设备和头显适配器 |
| Type-C 转网口转换器 | 1 | Pico 有线接入局域网 |

## 软件组成

| 软件 | 安装位置 | 说明 |
|---|---|---|
| KernelMind Apex 控制器端 | 天准003控制单元 | 与机器人交付版本配套的控制、相机和遥操服务 |
| 经典版 Apex Teleop | 上位机 | 连接机器人、切换模式、录制、回放和查看日志 |
| Apex Pico 客户端 | Pico 头显 | 网络连接、视频显示和全身遥操输入 |

## 网络说明

| 项目 | 说明 |
|---|---|
| 天准003控制单元 | 默认以 `6.6.7.100` 为例，现场修改后以实际地址为准 |
| 上位机 | 与天准003处于同一网段，地址不得冲突 |
| Pico 头显 | 由现场网络分配同网段地址，连接目标填写天准003实际 IP |

不要将 Pico 自身 IP 配置为与天准003相同的地址。

## 产品差异

- Skye/Luna 具有膝关节和全身动作映射，Marvin Pro 仅进行双臂遥操。
- Skye/Luna 使用 Pico 的腰部和腿部追踪组件，因此不使用 Meta Quest 作为标准全身遥操头显。
- Skye/Luna 当前继续使用[经典版 Apex Teleop](/software/apex-teleop/classic)。
